# 业务架构文档

> 纸书 · 大模型学习平台
> 最后更新：2026-09-27 · 对应版本：v1（tag `media-minio-gateway`）

## 1. 产品定位

面向大模型学习者的**视频内容平台**：将优质技术博主的视频内容按技术方向（Agent/Harness、MCP、RAG、提示词工程等）体系化组织，用户既能按技术主题系统学习，也能按博主追更，并通过收藏、播放历史形成个人学习中心。

## 2. 用户角色

| 角色 | 说明 | 能力 |
|---|---|---|
| 游客 | 未登录 | 浏览首页/分类/博主、观看视频 |
| 注册用户 | 手机号注册（Web）或微信登录（小程序） | 游客全部能力 + 收藏 + 播放历史 + 个人中心 |
| 博主 | 内容作者（以数据实体 blogger 存在） | 当前为后台维护的内容归属对象；暂无博主端自助发布 |

## 3. 业务模块划分

```
纸书平台
├── 内容发现
│   ├── 热门内容（热门视频 + 热门文章）
│   ├── 技术分类浏览（harness / mcp / rag / prompt）
│   └── 博主浏览（博主列表 + 博主主页视频）
├── 视频播放
│   ├── 播放器（进度拖动、封面、时长）
│   ├── 视频详情（标题、所属类别、标签、作者、收藏数）
│   └── 播放历史自动记录（含观看进度）
├── 用户中心
│   ├── 账号资料
│   ├── 我的收藏（视频/文章，可取消）
│   └── 浏览历史（可追溯、续看）
└── 认证
    ├── 手机号 + 验证码（Web）
    └── 微信授权快速登录（小程序）
```

## 4. 核心业务流程

### 4.1 注册与登录

- **Web**：输入手机号 → 获取验证码（开发期固定 `123456`）→ 未注册用户自动完成注册（昵称默认）→ 登录成功进入首页
- **小程序**：`wx.login` 静默授权 → 后端按 openid 识别/建号 → 直接登录，无感知

### 4.2 学习播放

```
首页/分类/博主页 ──选择视频──▶ 视频详情
                                 ├─ 观看（可拖动进度）
                                 ├─ 自动记录播放历史与进度（登录用户）
                                 └─ 收藏/取消收藏（登录用户）
```

### 4.3 内容组织的两条路径 + 标签

同一批视频可从三种维度到达：

1. **按技术分类**：RAG 检索、智能体框架、MCP 协议、提示词工程（每部视频归属一个技术类别）
2. **按博主**：李某某的AI课、Harness实验室、MCP研究所、LLM入门指南（每部视频归属一位作者）
3. **按标签**：一部视频可挂多个标签（如「RAG全流程实战」挂 RAG / 向量数据库 / Embedding），支持交叉检索，一部视频可同时属于多个主题

## 5. 信息架构（页面结构）

**Web（PC）**

```
首页（热门 + 技术分类 + 博主推荐）
├─ 视频详情页 /video/:id（播放器 + 标签 + 收藏）
├─ 登录页 /login
└─ 用户中心 /user
    ├─ 账号资料
    ├─ 我的收藏 /user/favorites
    └─ 浏览历史 /user/history
```

**微信小程序**

```
home 首页 ─ detail 详情 ─ login 登录
 ├ user 个人中心 ─ favorites 我的收藏
 └ history 浏览历史
```

两端业务能力对齐；小程序以微信登录替代手机号登录。

## 6. 业务数据模型

```
user（用户）
  │ 1
  │
  │ N                blogger（博主/作者）
favorite（收藏）       │ 1                    category（技术类别）
  │                    │                        │
  │ N                  │ N                      │ 1
  └── target ──▶ video（视频）◀──────────────────┘（每视频属一个类别）
                     │    │ N
history（浏览历史）───┘    │
  │                         │ N
  └── target ──▶ video    video_tag（关联）── N ── tag（标签）

article（文章）：归属博主、带技术分类 key 与热度，作为视频之外的补充内容
```

**核心实体业务含义**

| 实体 | 业务含义 | 关键关系 |
|---|---|---|
| user | 平台注册用户 | 拥有收藏、历史 |
| blogger | 内容作者 | 产出视频/文章 |
| category | 技术类别（也保留博主型分类记录） | 视频按类别归集 |
| video | 视频内容主体 | 属一位作者、一个类别、多个标签 |
| tag | 内容标签 | 与视频多对多 |
| article | 图文内容 | 属一位博主、带技术方向 |
| favorite | 收藏关系 | 用户 ↔ 视频/文章（唯一约束防重复） |
| history | 观看记录 | 用户 ↔ 视频/文章，记录进度与最近观看时间 |

## 7. 内容运营约定

- 视频文件存入对象存储（当前 MinIO 网关，数据落在 NAS），对象 key 规范：`<技术分类>/<英文文件名>.mp4`，与库内 media_key 一致
- 浏览器可播放要求 H.264/AAC 编码 MP4
- 新视频入库需维护：标题、作者、类别、标签、时长、封面
- 热门内容按 hot_score 排序（运营后台/脚本维护）

## 8. 业务规划

| 方向 | 规划能力 |
|---|---|
| 内容消费 | 搜索、智能推荐、评论点赞、视频转码（支持多格式）、封面自动生成 |
| 用户体系 | 真实短信服务、账号设置、会员体系（按需） |
| 创作者 | 博主端内容自助发布与数据看板 |
| 基础设施 | 阿里云 OSS（线上视频源）、Flyway 数据库版本管理、真实微信 AppID 接入 |
